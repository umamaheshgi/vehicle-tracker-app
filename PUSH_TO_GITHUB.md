**You need to create the repository on GitHub first:**

1. Go to: **https://github.com/new**
2. Set these details:
   - **Repository name**: `vehicle-tracker-app`
   - **Description**: `Vehicle Movement Tracker - React TypeScript app with Leaflet maps`
   - **Visibility**: ✅ **Public** (required for free GitHub Pages)
   - **Initialize**: ❌ **Do NOT** check "Add a README file" (we already have one)
   - **Add .gitignore**: ❌ None (we already have one)
   - **Choose a license**: ❌ None for now

3. Click **"Create repository"**

## Step 2: Push Your Code

After creating the repository, run these commands:

```bash
# Push to your GitHub repository
git push -u origin main
```

## Step 3: Deploy to GitHub Pages

```bash
# Deploy to GitHub Pages
npm run deploy
```

## Step 4: Enable GitHub Pages

1. Go to your repository: **https://github.com/umamaheshgi/vehicle-tracker-app**
2. Click **Settings** tab
3. Scroll to **Pages** section (left sidebar)
4. Under **Source**: Select **"Deploy from a branch"**
5. **Branch**: Select **"gh-pages"**
6. **Folder**: Select **"/ (root)"**
7. Click **Save**
